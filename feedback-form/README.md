# Форма зворотного зв'язку

Адаптивна форма для лендингу: ім'я, email, телефон, повідомлення, чекбокс згоди, кнопка «Надіслати».

**Стек:** HTML5 + Tailwind CSS + Vanilla JavaScript

## Структура

```
feedback-form/
├── index.html              — розмітка форми
├── assets/
│   ├── css/styles.css      — додаткові стилі
│   └── js/validation.js    — валідація та відправка
└── README.md
```

## Запуск

Відкрити `index.html` у браузері.
